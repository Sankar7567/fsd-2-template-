==============================================================================
MERN STACK LAB COMMANDS
==============================================================================

NODE & NPM
==========

node -v
Checks installed Node.js version.

------------------------------------------------------------

npm -v
Checks installed npm version.

------------------------------------------------------------

npm list --depth=0
Displays all installed packages in the current project.

------------------------------------------------------------

npm install
Installs all packages listed in package.json.

------------------------------------------------------------

npm install <package>
Installs a package locally for the current project.

Example

npm install express

------------------------------------------------------------

npm install -g <package>
Installs a package globally.

Example

npm install -g nodemon

------------------------------------------------------------

npm start
Starts a React application.

------------------------------------------------------------

node app.js
Runs an Express application.

------------------------------------------------------------

nodemon app.js
Runs Express and automatically restarts on file changes.

==============================================================================
